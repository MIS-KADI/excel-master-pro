> **સંપૂર્ણ ત્રિભાષી (Trilingual): ગુજરાતી (Gujarati) | हिन्दी (Hindi) | English**

## 🌟 મુખ્ય સુવિધાઓ (Key Features)

### ૧. 🌐 ત્રણેય ભાષાઓમાં સંપૂર્ણ સપોર્ટ (Trilingual Engine)
- **ગુજરાતી**, **हिन्दी**, અને **English** - એક જ ક્લિકમાં આખી એપ અને વેબસાઇટની ભાષા બદલાઈ જાય છે.
- તમામ ફોર્મુલાના નામ, સિન્ટેક્સ, રોજિંદા કામના ઉદાહરણો (Real-world scenarios), ટેબલ હેડર્સ, સ્ટેપ-બાય-સ્ટેપ સમજૂતી, એરર સોલ્યુશન અને પ્રો ટિપ્સ ત્રણેય ભાષામાં ઉપલબ્ધ છે.

### ૨. 📊 ટેબલ સાથે વિગતવાર ફોર્મુલા સમજૂતી (Visual Excel Tables)
- માત્ર લખાણ જ નહીં! દરેક ફોર્મુલા માટે **વાસ્તવિક એક્સેલ સ્પ્રેડશીટ ટેબલ** દર્શાવવામાં આવ્યું છે.
- કોલમ લેટર્સ (A, B, C, D...) અને રો નંબર્સ (1, 2, 3, 4...).
- એક્સેલ જેવો જ **ફોર્મુલા બાર (fx)**, સેલ કોઓર્ડિનેટ (જેમ કે F2) અને ગ્રીન હાઇલાઇટ સેલ.
- **પગલાવાર માર્ગદર્શન (Step-by-Step Guide)** અને **સામાન્ય ભૂલો અને ઉકેલ (Errors & Fix - #N/A, #VALUE!, #DIV/0!, #REF!)**.

### ૩. ⌨️ ૮૦+ એક્સેલ કીબોર્ડ શોર્ટકટ્સ (Keyboard Shortcuts)
- કેટેગરી મુજબ: સામાન્ય (Basic), નેવિગેશન (Navigation), ડેટા એન્ટ્રી (Data Entry), ફોર્મેટિંગ (Formatting), ફોર્મુલા (Formulas), રો અને કોલમ (Rows/Cols), ફિલ્ટર્સ (Filters).
- **Windows** અને **Mac** બંને પ્રકારના કીબોર્ડ માટે કી-કોમ્બિનેશન (Ctrl / Cmd, Alt / Option).
- એક ક્લિકમાં શોર્ટકટ કોપી કરવાનું બટન.

### ૪. 🧪 લાઈવ એક્સેલ પ્રેક્ટિસ પ્લેગ્રાઉન્ડ (Interactive Live Sandbox)
- બ્રાઉઝરમાં જ અસલી એક્સેલ જેવી શીટ!
- તમે સેલની કિંમતો જાતે બદલી શકો છો અને ઉપર ફોર્મુલા બારમાં `=SUM()`, `=AVERAGE()`, `=MAX()`, `=MIN()`, `=COUNT()`, `=IF()` લખીને લાઈવ પરિણામ જોઈ શકો છો!
- તૈયાર બિઝનેસ ટેમ્પલેટ્સ: સેલ્સ રિપોર્ટ, ગુણપત્રક (Marksheet), ઓફિસ ખર્ચ (Expenses), પગાર પત્રક (Salary).

### ૫. ⚡ સ્માર્ટ ફોર્મુલા સહાયક (AI Formula Builder)
- તમારે શું ગણતરી કરવી છે તે સિલેક્ટ કરો (જેમ કે: GST ટેક્સ ગણવો, પાસ-નાપાસ પરિણામ, લોન EMI, જન્મતારીખ પરથી ઉંમર, ID દ્વારા લુકઅપ).
- સેલ નંબર લખો અને ફોર્મુલા આપોઆપ જનરેટ થઈ જશે!

### ૬. 🏆 એક્સેલ ક્વિઝ અને ઇન્ટરવ્યુ ટેસ્ટ (Practice Quiz)
- એક્સેલના મહત્વના પ્રશ્નો, તાત્કાલિક સાચો/ખોટો જવાબ, માર્કસ અને વિસ્તૃત સમજૂતી.

### ૭. 🌙 ડાર્ક મોડ અને લાઈટ મોડ (Dark & Light Theme)
- સુંદર માઈક્રોસોફ્ટ એક્સેલ ગ્રીન થીમ સાથે ડાર્ક અને લાઈટ મોડ સ્વિચ. તમારી પસંદગી આપમેળે સેવ રહે છે.

### ૮. 🔊 અવાજ સાથે સમજૂતી સાંભળો (Voice Narration & Text-to-Speech)
- કોઈપણ ફોર્મુલાની વિગતમાં જઈને **"અવાજ સાંભળો 🔊"** બટન દબાવવાથી બ્રાઉઝર પોતે ગુજરાતી, હિન્દી કે અંગ્રેજીમાં આખી ફોર્મુલા અને રીત બોલીને સમજાવશે!

### ૯. ⚠️ એક્સેલ એરર્સ માસ્ટર ગાઈડ (Errors Master Guide)
- `#N/A`, `#VALUE!`, `#REF!`, `#DIV/0!`, `#NAME?`, `#NUM!`, `#SPILL!`, `#####` જેવી તમામ એરરો કેમ આવે છે તેનું વિશ્લેષણ, ખોટી ફોર્મુલા સામે સાચી ફોર્મુલા અને ૧ સેકન્ડમાં ફિક્સ કરવાની રીત.

### ૧૦. 🎮 ઇન્ટરેક્ટિવ કીબોર્ડ શોર્ટકટ ટ્રેનર ગેમ (Keystroke Trainer)
- તમારી શોર્ટકટ સ્પીડ વધારવા માટે લાઈવ ગેમ! સ્ક્રીન પર સવાલ આવશે (જેમ કે "ફાઇલ સેવ કરો"), અને તમારે તમારા કમ્પ્યુટરના કીબોર્ડ પરથી સાચી કી (`Ctrl` + `S`) દબાવીને સ્કોર વધારવાનો રહેશે.

### ૧૧. 📥 ડાઉનલોડ પ્રેક્ટિસ વર્કબુક ફાઈલો (.csv)
- અસલી ડેટાસેટ (વેચાણ લેજર, માર્કશીટ, પગાર પત્રક) સીધા જ `.csv` માં ડાઉનલોડ કરી તમારા પોતાના MS Excel કે Google Sheets માં પ્રેક્ટિસ કરી શકો છો.

### ૧૨. 🎓 સત્તાવાર એક્સેલ સર્ટિફિકેટ (Canvas Certificate Generator)
- ક્વિઝમાં ૭૦% થી વધુ માર્કસ મેળવ્યા બાદ તમારું નામ લખીને ગોલ્ડન સીલ સાથેનું સત્તાવાર ડિજિટલ સર્ટિફિકેટ જનરેટ કરો અને PNG ઈમેજ તરીકે ડાઉનલોડ કરો.

### ૧૩. 🤖 સ્માર્ટ નેચરલ લેંગ્વેજ AI ક્વેરી (Ask in Plain Words)
- સાદી ગુજરાતી કે હિન્દીમાં લખો (જેમ કે: "જીએસટી ગણવો", "બે નામ જોડવા", "જન્મતારીખ પરથી ઉંમર", "સૌથી મોટો નંબર"), અને સિસ્ટમ આપોઆપ શ્રેષ્ઠ ફોર્મુલા સૂચવશે.

### ૧૪. 📱 PWA એપ (Installable App on Mobile & PC)
- Progressive Web App: મોબાઇલ (Android / iPhone) અને કમ્પ્યુટર (Windows / Mac) પર એપ્લિકેશનની જેમ ઇન્સ્ટોલ કરી શકાય છે.
- ઑફલાઇન સપોર્ટ (ઇન્ટરનેટ વગર પણ કામ કરે છે).

## 🚀 આ વેબસાઇટ / એપ કેવી રીતે ચલાવવી? (How to Run)

### રીત ૧: ડાયરેક્ટ બ્રાઉઝરમાં ખોલો (Direct Open)
તમારા કમ્પ્યુટરમાં `d:\GSQAC AND SAT\EXCEL FORMULA\index.html` ફાઇલ પર ડબલ-ક્લિક કરો. તે સીધી જ Google Chrome, Microsoft Edge કે અન્ય બ્રાઉઝરમાં ખુલી જશે!

### રીત ૨: લોકલ સર્વર દ્વારા ચલાવો (Node.js Server)
ટર્મિનલમાં નીચેનો કમાન્ડ રન કરો:
```bash
node server.js
```
ત્યારબાદ તમારા બ્રાઉઝરમાં આ લિંક ખોલો:
👉 **http://localhost:3000**
